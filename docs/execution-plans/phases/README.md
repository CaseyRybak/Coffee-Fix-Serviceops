# Phase Slice Maps

This directory contains historical and current phase slice maps. A phase file describes the intended scope, boundaries, and acceptance criteria for that phase at the time it was planned.

Current status lives in:

- `project_notes.md`
- `docs/execution-plans/index.md`
- the latest relevant `docs/review/phase-XX-review.md`
- current `domains/<domain>/domain.md` files

Older phase files can mention deferred work, missing capabilities, or review gates that were accurate for that phase but are no longer current. Do not infer current backlog from an older phase file. If new work starts, create a new phase slice or explicitly reopen an existing one in `docs/execution-plans/index.md`.
