# Detailed Implementation Plans

This directory contains just-in-time implementation plans for phase slices.

Current plan:

Historical plans in this directory record how completed phases were implemented. They can contain unchecked task boxes, old active-phase handoff text, and deferred-scope language that was accurate at the time of that phase. Use `project_notes.md` and `docs/execution-plans/index.md` for current status.

When a future phase becomes active, create its detailed plan here before implementation starts. After a phase is implemented, reviewed, and handed off, keep the plan as a durable historical artifact unless the project intentionally archives it elsewhere.
