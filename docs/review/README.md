# Review Artifacts

This directory contains durable review records. Phase reviews and documentation audits are historical evidence for what was checked, found, fixed, accepted, or deferred at a specific point in time.

Use reviews this way:

- Latest phase review: evidence that the named phase was accepted or what remains open.
- Older phase reviews: historical context, not current backlog by themselves.
- Documentation audits: dated snapshots of documentation quality and consistency.
- `subagent-review-protocol.md`: current review process.

Current implementation status lives in `project_notes.md`, `docs/execution-plans/index.md`, current domain docs, current operations docs, and the latest phase review. If an older review says work is deferred, check whether a later phase review or domain doc marks that work as implemented before treating it as still open.
