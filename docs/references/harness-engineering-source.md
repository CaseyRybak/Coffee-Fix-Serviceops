# Harness Engineering Source

Primary reference:

- OpenAI, "Harness engineering: leveraging Codex in an agent-first world": https://openai.com/index/harness-engineering/

Project interpretation:

- Repository knowledge is the system of record.
- `AGENTS.md` files are maps and entry points.
- Plans are versioned artifacts.
- Application and repository context should be legible to agents.
- Work should be sliced, verified, reviewed, and reflected back into repo-local context.
