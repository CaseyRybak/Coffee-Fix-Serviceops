# Figma Reference Review

## Reference Location

The Figma export lives in `reference/figma`. It is a React/Vite prototype, not a raw Figma file.

## Use As Primary Reference For

- Public landing structure.
- Warm service-business visual tone.
- Color palette.
- Hero and CTA hierarchy.
- Repair request form behavior.
- Status preview concept.
- Mobile sticky CTA.
- Copy style for local repair service.

## Preserve

- Service bar with city, hours, phone, and call-to-action.
- Header with CoffeeFix Pro identity.
- Hero: repair with technician visit.
- Request form and success state.
- Brands, issues, process, trust, status preview, footer.
- Telegram as service convenience.

## Improve During Implementation

- Replace external Unsplash image with controlled local assets.
- Move inline styles into design tokens and component styles.
- Shorten the first-submit form.
- Add photo/video attachment.
- Add reviews or recent repairs.
- Add service conditions: diagnostics, visit, warranty, and B2B documents.
- Make the status preview closer to the real status page timeline.
