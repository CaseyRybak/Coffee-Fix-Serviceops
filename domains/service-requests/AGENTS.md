# Service Requests Domain Map

## Purpose

Owns the repair request lifecycle from intake to closure.

## Start Here

- `domain.md`
- `plans/`
- `decisions/`
- `docs/domain-maps/index.md`

## Core Concepts

- Service request.
- Request number.
- Request status.
- Intake symptoms.
- Clarification question.
- Status event.
- Technician assignment.

## Related Domains

- Customers provide contact and client type.
- Machines provide brand, model, and machine history.
- Technicians and scheduling handle assignment and visit windows.
- Inventory checks likely parts.
- AI agents produce suggestions.
- Notifications deliver status updates.
