# Customers Domain

## Responsibility

This domain stores private and B2B customer context. It supports low-friction request intake without requiring a full user account.

## First Use Cases

- Create or match customer by phone.
- Store optional Telegram handle.
- Store client type: private, office, coffee shop, restaurant, other.
- Link customer to service requests.

## Phase 02 Intake Ownership

Customer intake records are created from the public repair form without requiring an account. The customer domain owns the submitted name, phone, optional Telegram handle, and client type. Matching customers by phone remains a future use case; Phase 02 persists each submitted intake as a new customer record.
